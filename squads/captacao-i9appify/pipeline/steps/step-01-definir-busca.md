# Step 01 — Importar CSV do Apollo

## Tipo: Checkpoint (aguarda input do Ronaldo)

## Como exportar o CSV do Apollo

1. Acesse [app.apollo.io](https://app.apollo.io) → **Search** → **People**
2. Aplique os filtros recomendados:
   - **Job Title:** CEO, Dono, Founder, Sócio, Diretor Comercial
   - **Industry:** Health, Legal, Real Estate, Education, E-Commerce
   - **# Employees:** 1–50
   - **Location:** Brazil
3. Clique em **Export** → **Export to CSV** (máximo 50 contatos por exportação no plano free)
4. Salve o arquivo como `apollo-export.csv` dentro da pasta:
   ```
   squads/captacao-i9appify/input/
   ```
