# I9 Appify - Landing Page

Uma landing page moderna e de alta conversão desenvolvida para a **I9 Appify**, focada em automação, inteligência artificial e criação de apps.

## 🚀 Tecnologias Utilizadas

- **React** (Vite)
- **Tailwind CSS** (v4)
- **Framer Motion** (Animações avançadas)
- **Lucide React** (Ícones)

## 🛠️ Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/RonaldoSalvador/Landing-page-i9appify.git
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Rode o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

## 📦 Deploy

Projeto configurado para deploy fácil na Vercel, Netlify ou Cloudflare Pages.
